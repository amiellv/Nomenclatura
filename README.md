# 🧪 Nomenclatura

Aplicación web interactiva que analiza fórmulas químicas ingresadas por el usuario y genera automáticamente su nomenclatura en tres sistemas:

- Tradicional  
- Stock  
- Sistemática  

Diseñada para estudiantes, con una interfaz moderna, intuitiva y fácil de usar.

---

## 🚀 Características

- 🔍 Análisis automático de compuestos químicos  
- 🧾 Generación de nomenclatura en los 3 sistemas  
- 🧠 Identificación del tipo de compuesto (ácido, óxido, sal, hidróxido, etc.)  
- 🧮 Soporte para fórmulas con paréntesis (ej: Ca(OH)₂)  
- 📱 Interfaz moderna estilo app  
- 📑 Sistema de pestañas (resultado e historial)  
- 🕘 Historial de consultas  

---

## 🧪 Ejemplos

| Fórmula | Resultado |
|--------|---------|
| HClO | Ácido hipocloroso |
| HClO₂ | Ácido cloroso |
| HClO₄ | Ácido perclórico |
| NaCl | Cloruro de sodio |
| Ca(OH)₂ | Hidróxido de calcio |
